# SmartBuddy AI — AI-Powered Micro-Learning MiniApp

## About the Project
SmartBuddy AI is an AI-powered micro-learning application built using Amazon PartyRock as part of the **“The Waiting Room” challenge**.

The goal is to help users make productive use of short waiting periods by learning useful topics through simple explanations, practical examples, and interactive quizzes.

## Features
- AI-generated mini-lessons
- Multiple topics: Python, Web Development, Artificial Intelligence, Science, and General Knowledge
- Flexible 5-, 10-, and 15-minute learning sessions
- Beginner-friendly explanations and examples
- Interactive quizzes with revealable answers
- Shortened lessons for quick revision
- AI-powered question-and-answer functionality
- User-friendly interface and loading feedback

## Built With
- Amazon PartyRock
- AI-powered content generation
- TypeScript/TSX for the app source, where applicable
